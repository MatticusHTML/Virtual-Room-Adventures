VRA — Incoming character files
==============================

Drop new character images here (any filenames are fine).

Then tell Cursor in chat:
  - Character name
  - Universe (e.g. Fallout)
  - Ability name + description
  - Quote and lore (optional — we can draft them)
  - PC or NPC, faction, class (if you know them)

Files are moved into:
  assets/characters/<character-id>/default/
  assets/characters/<character-id>/cards/
  assets/characters/<character-id>/scenes/

After files are organized, you can delete them from this folder or leave it empty for the next character.
